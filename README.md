# 🌽👑 THE LEGEND OF SILKA — The Adventure of CornMan

A new game by Michael Nappier (xrpman / RedCandleKiller), built with Muse.
This repo is the game's own home — separate from the corn-games hub.

**Play Part One: The Feast and the Telling** — open `index.html`
(GitHub Pages serves it at the site root).

## Layout
- `/index.html` + `/sprites-data.js` + `/title-scene.js` + `/music/` + `/art/`
  — the playable build (plain files, no build step, no server)
- `/project/` — the full project: source, plan, characters, sprites,
  castle and cave packs, maps, and the pack verdict log

## Part One
Title (animated) → play as young Pearl at the harvest feast →
a hundred harvests later, play as CornMan in the Castle-Foot Village →
the Telling at old Pearl's hearth.
